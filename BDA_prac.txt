============================================================ Q2. WORD
COUNT USING MAPREDUCE IN PYTHON (mrjob)
============================================================

PURPOSE: Count how many times each word occurs in a text file using a
Mapper and Reducer.

INSTALL (PowerShell): python -m pip install mrjob

CREATE FILE: q2.py

from mrjob.job import MRJob

class WordCount(MRJob): # Mapper: emit each word with a count of 1. def
mapper(self, _, line): for word in line.lower().split(): yield word, 1

    # Reducer: add the counts for each word.
    def reducer(self, word, counts):
        yield word, sum(counts)

if name == ‘main’: WordCount.run()

CREATE INPUT FILE: input.txt

hello world hello python world python

RUN (from the folder containing q2.py and input.txt): python q2.py
input.txt

EXPECTED RESULT (order may vary): “hello” 2 “python” 2 “world” 2

NOTE: - A real mrjob MapReduce program requires mapper() and reducer()
methods. If your instructor says not to define your own functions, ask
whether a built-in Counter demonstration is acceptable; Counter alone is
word counting, not MapReduce. - This simple program splits on
whitespace, so punctuation is treated as part of a word.

============================================================ Q3.
FLajolet–Martin DISTINCT-COUNT ESTIMATION IN PYTHON
============================================================

PURPOSE: Estimate the number of distinct items in a stream using hashing
and trailing zeros.

CREATE FILE: q3.py

import hashlib

data = [“apple”, “banana”, “apple”, “mango”, “grape”, “banana”,
“orange”] R = 0

for item in data: h = int(hashlib.sha256(item.encode()).hexdigest(), 16)
binary = bin(h)[2:] zeros = len(binary) - len(binary.rstrip(“0”)) R =
max(R, zeros)

print(“Estimated distinct elements:”, 2 ** R) print(“Actual distinct
elements:”, len(set(data)))

RUN: python q3.py

HOW IT WORKS: 1. Hash each item. 2. Convert the hash to binary. 3. Count
trailing zeros. 4. Keep the maximum count R. 5. Estimate using 2**R.

NOTE: This is the basic single-register Flajolet–Martin estimate. It can
be inaccurate on small data; the actual count is printed for comparison.

============================================================ Q4. DGIM
ALGORITHM IN PYTHON
============================================================

PURPOSE: Estimate the number of 1 bits in a recent window of a binary
stream using buckets.

CREATE FILE: q4.py

Each bucket is [size, timestamp].

stream = [1, 0, 1, 1, 0, 1, 0, 1] N = 8 buckets = []

for t, bit in enumerate(stream, 1): # Remove buckets whose timestamps
are outside the last N bits. buckets = [b for b in buckets if b[1] > t -
N]

    if bit == 1:
        buckets.insert(0, [1, t])

        # While there are more than two buckets of a size, merge the two
        # oldest buckets of that size into one bucket of double size.
        while True:
            sizes = sorted(set(b[0] for b in buckets))
            merged = False

            for size in sizes:
                indexes = [i for i, b in enumerate(buckets) if b[0] == size]

                if len(indexes) > 2:
                    # Buckets are newest-first; merge the two oldest.
                    i_old = indexes[-1]
                    i_next_old = indexes[-2]
                    buckets[i_next_old] = [
                        size * 2, buckets[i_next_old][1]
                    ]
                    buckets.pop(i_old)
                    merged = True
                    break

            if not merged:
                break

Buckets are newest-first. Count all but the oldest fully, and half the oldest.

if buckets: estimate = sum(b[0] for b in buckets[:-1]) + buckets[-1][0]
/ 2 else: estimate = 0

print(“Buckets (size, timestamp):”, buckets) print(“Estimated number of
1s in last”, N, “bits:”, estimate)

RUN: python q4.py

NOTE: This is a teaching implementation of DGIM’s bucket-merging idea.
DGIM uses approximate counts; the oldest bucket is counted as half its
size.

============================================================ Q7.
REGRESSION IN R
============================================================

A. LINEAR REGRESSION

CREATE / RUN IN RStudio: x <- c(1, 2, 3, 4, 5) y <- c(2, 4, 5, 4, 6)

m <- lm(y ~ x) print(summary(m)) plot(x, y) abline(m, col = “red”)

B. LOGISTIC REGRESSION

x <- 1:6 y <- c(0, 0, 0, 1, 1, 1)

m <- glm(y ~ x, family = binomial) p <- predict(m, type = “response”)
print(p) plot(x, p, type = “b”, ylim = c(0, 1))

C. MULTIPLE LINEAR REGRESSION

x1 <- 1:5 x2 <- c(2, 4, 3, 5, 6) y <- c(5, 8, 9, 12, 15)

m <- lm(y ~ x1 + x2) print(summary(m)) plot(y, predict(m), xlab =
“Actual”, ylab = “Predicted”) abline(a = 0, b = 1, col = “red”)

MEMORY TRICK: Linear = lm(y ~ x) Logistic = glm(y ~ x, family =
binomial) Multiple = lm(y ~ x1 + x2)

============================================================ Q8.
GIRVAN–NEWMAN COMMUNITY DETECTION IN R
============================================================

PURPOSE: Find communities in a network using edge betweenness.

FIRST TIME ONLY — install the package in R: install.packages(“igraph”)

CREATE / RUN IN RStudio:

library(igraph)

Create an undirected graph from an edge list.

edges <- c(“A”, “B”, “A”, “C”, “B”, “C”, “C”, “D”, “D”, “E”, “D”, “F”,
“E”, “F”)

g <- graph(edges, directed = FALSE)

plot(g, main = “Original Network”)

Girvan–Newman method: edge-betweenness community detection.

communities <- cluster_edge_betweenness(g)

print(communities) print(membership(communities)) plot(communities, g,
main = “Detected Communities”)

NOTE: Install igraph only once. On later runs, use library(igraph).
cluster_edge_betweenness() performs the Girvan–Newman community
detection method.
